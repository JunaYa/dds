# 桌面小组件

iOS 和 Android 的系统小组件库提供三个入口：

- **喂奶**：固定显示最近一次喂奶记录，配置时只需选择宝宝。
- **睡眠**：固定显示最近一次睡眠记录，配置时只需选择宝宝。
- **其他记录**：选择宝宝和任意记录类型，包括在应用中新增的自定义类型。

每个实例只显示一种记录。可重复添加“其他记录”，分别配置为换尿布、洗澡、自定义记录等；不同实例也可选择不同宝宝。轻点小组件会打开对应宝宝的记录表单，确认保存后更新最近记录时间。

先打开应用创建宝宝和需要的记录类型，再从系统的小组件库添加 Little days 小组件。iOS 长按小组件后选择“编辑小组件”；Android 可通过桌面启动器的编辑入口重新配置。新增或修改类型后需打开应用，让类型列表同步到小组件。

iOS 保留原来的 `RecentRecord` kind 和配置参数，Android 保留原来的 `RecentRecordWidget` provider 与逐实例配置，因此原有单类型小组件可继续使用。新增的喂奶、睡眠小组件需要用户从系统小组件库添加，应用不会自动放置到桌面。

宝宝或记录类型被删除后，小组件提示重新配置，不会改成其他宝宝或类型。喂奶、睡眠专用小组件的内置类型被删除时，需要先在应用中恢复对应类型。

## 检查

前端桥接测试覆盖自定义类型同步、喂奶和睡眠入口、宝宝归属、保存后时间更新以及无效配置：

```sh
pnpm exec vitest run src/features/little-days/widget/RecentRecordBridge.test.tsx
```

Android 的 `RecordWidgetKindTest` 验证专用类型映射、旧通用类型配置和未知 provider 拒绝；通过 Gradle 的 `:app:testArm64DebugUnitTest` 运行。iOS 的 `RecentRecord` 扩展目标需要构建验证三个 Widget 的注册与 App Intent 元数据。安装后还需在真机确认系统小组件库、配置、点击和刷新行为。

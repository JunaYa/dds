# Siri 快捷记录（iOS）

支持 iOS 16.4 及以上。重新构建、安装应用后，在系统「快捷指令」中搜索应用的「记录奶量」「记录换尿布」动作。也可以尝试对 Siri 说「用 Little days 记录奶量」或「用 Little days 记录换尿布」；触发词里的应用名称以设备识别的实际名称为准。Siri 会收集奶量或尿布类型，再打开应用。

应用中核对宝宝、时间和内容，点击保存才会产生记录。多个宝宝必须显式选择；只有一个宝宝时预选。首次使用时先完成宝宝创建。取消会丢弃当前请求。此版本不提供锁屏静默保存，系统可能要求解锁。

## 实现

- `src-tauri/gen/apple/Sources/dds/RecordIntents.swift`：宿主应用 target 中的 App Intents 和 App Shortcuts 定义。必须编入宿主 Swift target，供 Xcode 提取快捷指令元数据，不能只放在 Tauri 静态插件中。
- `src-tauri/plugins/native-navigation/ios/Sources/SiriInbox.swift`：同时编入宿主和插件，使用应用沙盒 Application Support/SiriInbox 下的原子 JSON 文件传递请求，不依赖 WebView 存活。当前没有独立 Intent 扩展，无需 App Group。
- 原生插件仅提供读取与确认删除接口。应用在启动、回到前台及可见期间轮询收件箱，不会因冷启动漏掉一次性事件。
- React 使用现有 RecordForm、工作区提交及同步流程。请求中的 UTC 时间转换为现有本地日期时间格式。只对仍使用预期字段、选项及 mL 单位的内置记录类型预填；修改过的类型要求用户手动记录。
- 保存的 `source.format = siri` 与 `source.data.requestId` 用于保存后、确认删除前崩溃时的去重。保存失败不删除请求，删除失败提供重试。未确认时退出应用，下次仍能恢复。

`project.yml` 和已提交的 Xcode project 都包含 Swift source 接线。若重新执行 Tauri iOS init，需要保留这些接线；仅有插件源码不足以注册系统快捷指令。

## 验证

自动化覆盖参数校验、单位及选项变更、本地时间转换、确认保存、取消、多宝宝选择、保存失败、重新挂载恢复和已保存请求去重。

发版前使用签名真机验证：

1. 安装后两个动作出现在快捷指令中，中文 Siri 能触发并追问参数。
2. 冷启动、应用已打开、后台恢复时都只出现一个确认表单。
3. 锁屏要求解锁后可继续；未配置宝宝时先完成创建再接收请求。
4. 确认后重启不会重复新增；取消不生成记录；保存失败保留输入。
5. 中英文、多个宝宝、修改过的记录字段和本地时区显示正确。

Siri 语音识别和锁屏行为以真机验收为准；模拟器编译及前端测试不能验证这些系统行为。
